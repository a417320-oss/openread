# PDF 图片文字识别

打开 PDF，在阅读器顶部工具栏点击“识别 PDF 图片文字”。输入 PDF 页码范围
（从文件第一页算起，与印刷页码可能不同），选择简体中文、繁体中文或英文，
然后开始识别。建议先处理需要总结的章节；不会默认扫描整本长书。

- OCR 引擎和语言包随应用一起分发，在本机处理，无需 API 密钥、模型额度或网络。
- 已有足够可提取文字的页面以及同语言的缓存结果会自动复用。选择“重新识别”可重跑。
- 逐页保存，可随时取消；再次打开应用仍可使用已完成的结果。
- 结果用于 AI 章节提取、向量索引的源文字、CLI PDF 页读取，也可导出为 TXT。
- 阅读器显示的原 PDF 不变；此版本不会向原文件写入可选择的透明文字层。
- OCR 不保证正确还原多栏、表格、手写、模糊图片。人名、数字、引用请对照原图。

识别之后，可告诉 AI “总结 PDF 第 10–20 页”。如果以前的对话已经包含
“没有可读取内容”的工具结果，重新提问或新建对话，避免沿用旧结论。
已有的向量索引不会自动删除；重新建立索引时会使用保存的 OCR 文字。

## 数据保存

结果保存在资料库目录的 `pdf-ocr/<PDF内容SHA256>-<页码>.json`。缓存按文件
内容区分，重名、替换文件不会混用结果。迁移资料库时一起迁移。OCR 缓存不通过
现有云同步自动上传；如需在其他设备使用，可再次识别或复制本地缓存。

## 开发与验证

`pnpm --filter app build` 会先准备本地 OCR 资源。`pnpm test:ocr` 覆盖页码范围、
缓存、取消、错误和 PDF 页读取。`node scripts/ocr-smoke.mjs` 用合成的扫描页
执行实际 OCR，避免使用或发布私人书籍。详见根目录 README 的构建命令。
