# PDF 图片文字识别

打开 PDF，在 Windows 阅读器顶部点击“识别 PDF 图片文字”，或在 Android
阅读器中轻点页面后点击“OCR”。输入 PDF 页码范围
（从文件第一页算起，与印刷页码可能不同），选择简体中文、繁体中文或英文，
然后开始识别。建议先处理需要总结的章节；不会默认扫描整本长书。

- OCR 引擎和语言包随应用一起分发，在本机处理，无需 API 密钥、模型额度或网络。
- 已有足够可提取文字的页面以及同语言的缓存结果会自动复用。选择“重新识别”可重跑。
- 逐页保存，可随时取消；再次打开应用仍可使用已完成的结果。
- 两端识别完成后可点击“导出 EPUB”。EPUB 正文可选择和搜索，目录对应原 PDF 页码，
  并包含范围内已有的 PDF 文本。Android 通过系统菜单保存或分享，Windows 弹出保存对话框。
- Windows 也支持导出 TXT。Windows 的 AI 章节提取、向量索引和 CLI PDF 页读取会使用已识别的文字。
- 阅读器显示的原 PDF 不变；此版本不会向原文件写入可选择的透明文字层。
- OCR 不保证正确还原多栏、表格、手写、模糊图片。人名、数字、引用请对照原图。

Windows 端识别之后，可告诉 AI “总结 PDF 第 10–20 页”。如果以前的对话已经包含
“没有可读取内容”的工具结果，重新提问或新建对话，避免沿用旧结论。
已有的向量索引不会自动删除；重新建立索引时会使用保存的 OCR 文字。

## 数据保存

结果逐页保存在应用资料库的 `pdf-ocr` 目录内。Windows 按 PDF 内容识别缓存，
Android 按书库记录与本地文件属性识别缓存。可通过 EPUB 在不同设备上阅读已识别的文字。

## 开发与验证

`pnpm --filter app build` 和 `pnpm --filter @readany/app-expo build:reader` 会准备各端的本地 OCR 资源。
`pnpm test:ocr` 覆盖页码范围、缓存、取消、EPUB 正文和目录。`node scripts/ocr-smoke.mjs` 用合成的扫描页
执行实际 OCR，避免使用或发布私人书籍。详见根目录 README 的构建命令。
